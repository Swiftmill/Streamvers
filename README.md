# Streamvers
Streaming Project

## Aperçu

XalaFlix est une expérience de streaming fictive inspirée des interfaces modernes de plateformes vidéo. Le site est intégralement statique et propose plusieurs pages thématiques (Accueil, Films, Séries, Animés et Directs) partageant une identité visuelle commune.

## Structure

- `index.html` — page d'accueil avec mise en avant des tendances et recommandations.
- `films.html`, `series.html`, `anime.html`, `directs.html` — catalogues thématiques.
- `detail.html` — page de détail d'un contenu avec résumé, métadonnées et suggestions associées.
- `assets/css/style.css` — styles globaux (palette sombre néon, responsive, top 10, cartes médias, etc.).
- `assets/js/data.js` — catalogue de contenus (films, séries, animés et directs) et configuration des pages.
- `assets/js/app.js` — logique d'affichage : rendu des sections, top 10, recherche, filtres et navigation.
- `assets/js/detail.js` — affichage dynamique de la page de détail (récupération du contenu, navigation, recommandations).

## Utilisation

1. Ouvrir l'un des fichiers HTML dans un navigateur moderne (Chrome, Firefox, Edge…).
2. Naviguer entre les pages via le menu supérieur ou les liens du pied de page.
3. Cliquer sur une carte média pour accéder à sa page de détail (synopsis, bande-annonce, contenus similaires).
4. Utiliser la recherche ou les filtres pour parcourir le catalogue fictif.

Aucune compilation n'est nécessaire : il suffit d'ouvrir les fichiers HTML pour explorer l'interface.
